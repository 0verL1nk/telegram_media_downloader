欢迎使用 Telegram Media Downloader

三个确认即可开始:文件放哪里、用哪个 Telegram 账号、数据存在哪。之后一切都在左边的 Telegram 窗口、右边任务面板和托盘里。
1
选择下载目录

下载完成的媒体文件保存到这里,可随时在设置中更改。

E:\TelegramMediaDownloader\Downloads
2
登录 Telegram

在主界面左侧的 Telegram 窗口扫码或手机号登录 —— 一次登录,长期有效,不需要任何额外配置。

3
数据目录

任务数据库、登录 profile 与缓存都保存在此,可在设置中整体迁移。

E:\TelegramMediaDownloader
