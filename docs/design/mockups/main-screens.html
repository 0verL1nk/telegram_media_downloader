欢迎使用 Telegram Media Downloader

三个确认即可开始:文件放哪里、用哪个 Telegram 账号、数据存在哪。之后一切都在托盘和任务列表里。
1
选择下载目录

下载完成的媒体文件保存到这里,可随时在设置中更改。

E:\TelegramMediaDownloader\Downloads
2
在 Telegram 窗口登录

切换到「Telegram」页,用手机扫码或手机号登录——就像浏览器一样一次登录,之后长期有效。

不需要 API ID / 验证码之外任何配置
3
数据目录

任务数据库、登录 profile 与缓存都保存在此,可在设置中整体迁移。
