# TMD 客户端 UI/UX 设计规范(v0.3,已定稿)

> 依据:2026-09-27 定稿样稿 `docs/design/mockups/main-screens-v2.html`(五屏)。
> 参考:deepseek-harness 官方 UI(双层 token、克制用色、就地保存);差异:本产品以 Telegram 蓝为唯一强调色。
> 实现标准:**细化、精细、美观** —— 每个像素级间距/对齐/圆角/字重都按下表执行,不作即兴发挥。

## 1. 布局架构(三态)

```
┌ 标题栏 36px(自绘,拖拽区 + 窗口按钮)────────────────────────┐
├ 图标栏 64px ─┬ 内容区 ────────────────────────────────────┤
│ ✈ Telegram   │  ① 分栏态:Telegram Web ─ 拖拽条 5px ─ 任务面板 360px │
│ ↓ 任务·角标   │  ② 任务全览态(点"任务"):Web 收起,表格占满      │
│ ≡ 日志       │  ③ 设置/日志:整页;设置 = 左类别 190px + 卡片     │
│ …            │                                            │
│ ⚙ 设置(沉底) │                                            │
├ 状态栏 30px ─ 全局:下载中·速度·已完成·失败 | 托盘运行中·版本 ──┤
└────────────────────────────────────────────────────────────┘
```

- 图标栏项:44×44 按钮,圆角 12;active = 蓝软底(`--accent-soft`)+ 蓝字;任务图标带角标(进行中数量)
- 分栏:任务面板宽 360px 默认,拖拽条可 280–560 拖动;拖到 ≤200 松手 = 折叠(等价"任务全览");Web 收起时面板隐藏,点"Telegram"还原上次宽度(宽度/折叠状态持久化)
- 视图记忆:上次所在态(分栏/全览/设置页)启动恢复

规范:
- **颜色纪律**:强调色只出现于:主按钮/进度条/选中态/链接/角标;成功仅 ✓ 与完成标记;失败仅错误行与 ✕。其余一律中性灰。禁止渐变背景(品牌 mark 除外)、禁止阴影除弹层。
- 圆角:控件 8 / 行卡片 10 / 容器卡片 12 / 胶囊 999 / 图标栏按钮 12
- 边框:1px;卡片 `--border-l1`;表行分隔 `--border-l2`
- 字体:系统栈(`-apple-system, "Segoe UI", "Microsoft YaHei", "PingFang SC"`);路径/元数据用 `Consolas` mono
- 字级(仅 4 档字重 400/500/600/700):页面题 20/700 · 卡片题 14.5/600 · 正文 13/400 · 行题 13.5/600 · 次级 11.5–12.5/400–500 · 状态栏 11.5/400
- 行高密度:表格行 54px;面板行 56px(双行);图标栏项 44px;状态栏 30px

## 3. 组件规格

- **按钮**:高 36;主 = 蓝底白字 600;次 = 白底 1px `--border-l1`;幽灵 = 无框灰字 hover 底;就地保存组右对齐(重置/应用)
- **胶囊 tabs**:高 28–32;选中蓝软底蓝字 600,数字同色;未选灰
- **进度条**:高 5(表格)/4(面板),圆角 999;下载蓝、完成绿、失败红(停在失败处)
- **状态图标块**:26×26 圆角 8;下载蓝软底 ↓;完成绿软底 ✓;失败红软底 ✕
- **开关**:40×22,开=蓝,关=`--track`;滑块 16 白
- **步进器**:34/44/34 三段,边框包围,中段加粗居中
- **输入**:高 38,圆角 8,1px 边;聚焦 = 蓝边 + 2px 蓝软晕
- **任务面板行**:图标 + 文件名(省略号)+ 行内操作(悬停显现);第二行 = 进度条 + "68% · 3.1 MB/s"(失败行显示红色原因,如 "URL 已过期 · 重开媒体可续")
- **查看器注入按钮**:原生样式接管(实现细节见注入脚本 spec);样稿中高亮仅为示意,实际与原生一致
- **空状态**:中性;任务空 = "把媒体的下载按钮点亮,任务会出现在这里"(文案细化时定稿);日志空/列表空同理,无插画

## 4. 交互规范

- 悬停:行 → `--bg-layer`;图标按钮 → `--bg-hover`;所有可点元素 cursor: pointer
- 键盘:↑↓ 选择任务行;Enter 打开文件;Del = 取消(确认);Esc 关详情/收起面板;Ctrl+1..4 切视图
- 拖拽条:hover 变蓝;拖动实时重排;双击 = 折叠/还原
- 状态→文案映射(错误必须可行动):URL 过期 → "重新打开该媒体后点击下载即可从断点继续"
- 所有即时操作(暂停/取消/重试)在点击后 ≤100ms 内给出视觉反馈(按钮即时态,不等后端)

## 5. 与功能任务(C1-C5)衔接

- C1 通知 / C2 任务栏进度 / C3 窗口记忆 / C4 自启托盘:设置页归属见样稿第④屏("托盘与启动"新类别)
- C5 任务列表:即第③屏的表格 + 面板右键菜单(右键 = 暂停/继续/取消/重试/打开文件/打开位置/复制文件名)
- 设置"关闭窗口时:驻留托盘/直接退出"与 C4 同批实现

## 6. 验收(细化美观的量化门槛)

- [ ] 与样稿逐屏对照:布局比例(64/360/36/30)、间距、圆角、字级一致
- [ ] 深色模式全页面无漏网硬编码色(抽查 devtools 无 #fff/#000 直写)
- [ ] 三种形态切换无跳变(Web 显隐与面板宽度过渡 ≤120ms ease-out)
- [ ] 悬停/聚焦/激活三态在所有可点元素可用且一致
- [ ] 长文件名两处截断行为一致(表格列省略、面板行省略)
- [ ] 1440×900 与 1280×800 两个窗口尺寸均无错位
